# Capybara's Outing (카피바라의 나들이)

libGDX로 만든 2D 플랫포머입니다. PC, 안드로이드, 모바일 웹에서 플레이할 수 있습니다.

## 바로 플레이

- **웹 (아이폰, 안드로이드, PC 브라우저):** https://jinyeong0402.github.io/capybaras-outing/
- **안드로이드 설치 파일:** https://jinyeong0402.github.io/capybaras-outing/capybaras-outing.apk (설치할 때 출처를 알 수 없는 앱을 허용해야 합니다)

휴대폰은 가로로 돌려서 플레이합니다. 아이폰 전용 앱은 Mac과 Xcode가 있어야 빌드할 수 있어 웹 버전으로 지원합니다.

**아이폰 전체화면:** Safari에서 공유 버튼을 누르고 `홈 화면에 추가`를 선택한 뒤, 홈 화면 아이콘으로 실행합니다. 무음 모드에서는 소리가 나지 않습니다.

## 스토리

아빠 카피바라의 자식 3명이 나들이 길에 뿔뿔이 흩어졌습니다. 아빠는 귤을 모으고 노천탕에서 쉬어 가며 낮의 초원, 해질녘의 나루터, 밤의 들판을 지나 아이들을 한 명씩 찾아갑니다.

- 각 라운드의 **깃발 앞에 자식이 한 명씩** 기다리고 있습니다. 가까이 가면 `Dad!` 하고 부릅니다.
- 귤을 모두 모아 깃발에 닿으면 자식을 찾고 라운드가 끝납니다.
- 찾은 자식은 다음 라운드부터 **아빠 뒤를 통통 뛰며 따라옵니다.**
- 3명을 모두 찾으면 처음의 낮 초원에 온 가족이 모여 기뻐하는 엔딩이 나오고, 화면이 원형으로 닫히며 `THE END`로 끝납니다.

## 라운드

| 라운드 | 이름 | 배경 | 함께 다니는 자식 | 내용 |
|---|---|---|---|---|
| 1 | Sunny Meadow | 밝은 낮 | 0명 | 몬스터 없는 점프맵. 스위치와 문, 엘리베이터, 불타는 바닥 |
| 2 | Sunset Ferry | 해질녘 | 1명 | 움직이는 배와 무너지는 발판. 멧돼지, 고슴도치 등장 |
| 3 | Derpy's Night | 밤 | 2명 | 멍청하지만 끈질긴 몬스터 Derpy가 계속 쫓아옴 |

## 조작

홈 화면의 `GAME START`, `HOW TO PLAY` 버튼과 게임 오른쪽 위 톱니바퀴(음소거, 일시정지/재개, 홈)는 마우스나 터치로 누릅니다. 휴대폰에서는 화면의 왼쪽, 오른쪽, 점프, 방패(Zen) 버튼으로 조작합니다.

| 키 | 동작 |
|---|---|
| 방향키 / A, D | 이동 |
| Space | 점프 (길게 누르면 더 높이) |
| X / 왼쪽 Shift | Zen 모드 (게이지가 가득 찼을 때) |
| P / Esc | 일시정지, 재개 |
| R | 현재 라운드 재시작 |
| Q | 일시정지 중 홈 화면으로 |
| M | 음소거 |
| 홈 화면에서 1~3 | 라운드 연습 |

## 게임 규칙

- **귤:** 라운드의 귤을 모두 모아야 깃발이 열립니다. 연속으로 먹으면 콤보로 점수 배수(최대 9배)와 효과음 음높이가 올라갑니다.
- **친구 스택:** 멧돼지를 밟으면 친구가 되어 머리 위에 올라앉고(최대 3마리), 공격을 한 번씩 대신 막습니다. 다음 라운드로 이어지지만 죽으면 모두 사라집니다.
- **노천탕:** 시작 지점이자 리스폰 지점입니다. 가만히 있으면 Zen 게이지가 찹니다.
- **Zen 모드:** 4.5초 동안 세상만 35% 속도로 느려지고, 아빠는 정상 속도로 움직이며 다치지 않습니다. 단, 구덩이에 빠지면 죽습니다.
- **죽었을 때:** 마지막 노천탕에서 다시 시작합니다. 모은 귤과 열린 문은 그대로이고, 따라오던 자식도 함께 돌아옵니다.
- **황금 귤:** 찾기 어려운 곳에 있는 선택 요소로, 1000점과 함께 Zen 게이지를 가득 채웁니다.

### 적과 장치

| 대상 | 특징 | 대처 |
|---|---|---|
| 멧돼지 | 구간을 왕복 | 밟으면 친구가 됨 |
| 고슴도치 | 걷다가 가시를 세움, 밟으면 다침 | 뛰어넘기 |
| Derpy | 끝까지 쫓아오지만 잘 미끄러지고, 벽에 머리를 박고, 쫓던 걸 잊고, 구덩이에 빠지면 하늘에서 떨어져 돌아옴 | 밟으면 잠시 기절. 친구는 안 됨 |
| 불타는 바닥 | 주기적으로 켜짐, 켜지기 전 깜빡임 | 타이밍 맞추기 |
| 금 간 발판 | 밟으면 0.6초 뒤 무너지고 2.8초 뒤 복구 | 빨리 지나가기 |

### 등급

등급은 점수가 아니라 떨어진 횟수와 시간으로 정해집니다.

| 등급 | 조건 |
|---|---|
| S | 2번 이하로 떨어지고 7분 이내 |
| A | 6번 이하로 떨어지고 10분 이내 |
| B | 14번 이하로 떨어짐 |
| C | 15번 이상 떨어짐 |

## 과제 요구사항 대응

| 요구사항 | 구현 |
|---|---|
| 서로 다른 3개 이상의 레벨 | 3개 라운드. 맵 구조, 등장 적과 오브젝트, 색과 배경, 배경음, 분위기 입자가 모두 다름 |
| 전체 클리어 안내와 재시작 | 가족 엔딩과 `THE END` 뒤 `ALL ROUNDS CLEAR!` 결과 화면에 등급과 기록 표시, 버튼으로 1라운드부터 다시 시작 |
| 카메라 | 데드존, 진행 방향 앞보기, 발판 기준 수직 추적, 화면 흔들림, Zen 줌, 깃발에서 시작하는 인트로 패닝, 문 열림 연출, 클리어 상승 연출 |
| 독창적 요소 3개 이상 | 친구 스택, Zen 모드, 노천탕, Derpy AI, 따라오는 자식들, 귤로 여는 깃발과 콤보 |
| 일시정지와 재개 | 톱니바퀴 메뉴 또는 P / Esc. 시뮬레이션과 음악이 함께 멈추고, 창을 최소화해도 자동으로 멈춤 |

## 실행과 빌드

```bash
./gradlew lwjgl3:run
```

Windows에서는 `gradlew.bat`을 사용합니다.

| 명령 | 결과 |
|---|---|
| `lwjgl3:run` | PC에서 실행 |
| `lwjgl3:jar` | 실행 파일 JAR (`lwjgl3/build/libs`) |
| `core:test` | 규칙 테스트와 봇 클리어 테스트 |
| `android:assembleDebug` | 안드로이드 APK (`android/build/outputs/apk/debug`) |
| `teavm:buildWeb` | 웹사이트 (`teavm/build/dist/webapp`) |

OneDrive 폴더에서 빌드하면 파일 잠금으로 `Failed to clean up stale outputs`가 가끔 납니다. 다시 실행하거나 OneDrive 밖에서 빌드하면 됩니다.

## 구조

```
core/src/main/java/io/jbnu/test
├─ Main.java      공용 자원 생성, 화면 전환, 최고 기록 저장
├─ world/         게임 규칙. 그래픽·소리·입력 장치에 의존하지 않음
├─ level/         JSON 레벨 파일 파서
├─ render/        월드와 HUD 그리기, 카메라, 배경, 입자, 따라오는 자식, 코드 생성 스프라이트
├─ screen/        홈, 플레이, 엔딩, 결과 화면
├─ ui/            마우스·터치 버튼, 설정 아이콘, 터치 조작
└─ audio/         효과음과 배경음 관리
assets/levels/    라운드 데이터(JSON). 코드 수정 없이 맵 편집 가능
assets/audio/     tools/generate_audio.py가 합성한 WAV
```

수업 기본 범위를 넘어 적용한 설계:

- **로직과 표현의 분리:** `GameWorld`는 사건만 알리고(`WorldListener`, 옵저버 패턴) 소리와 입자는 `PlayScreen`이 처리합니다.
- **고정 시간 간격 물리:** 120Hz로 계산해 프레임 속도와 관계없이 같은 물리 결과가 나옵니다.
- **데이터 주도 레벨:** 맵, 적, 함정, 자식 위치를 JSON으로 정의합니다.
- **조작감 보정:** 코요테 타임, 점프 입력 버퍼, 가변 점프 높이, 가속과 감속.
- **다형성과 상태 기계:** `Enemy` 계층, Derpy AI, 발판 상태.
- **경로 기록 추적:** 자식들은 아빠가 지나간 길을 원형 버퍼에 기록해 일정 간격으로 따라갑니다(`FamilyTrail`).
- **객체 풀:** 입자와 점수 팝업을 재사용합니다.
- **절차적 에셋:** 적 스프라이트, 배경, 효과음, 배경음을 코드로 생성합니다.
- **자동 테스트:** `GameWorldTest`는 규칙을 검증하고, `LevelPlaythroughTest`는 봇이 실제 물리와 입력만으로 라운드를 클리어하는지 확인합니다.

게임에서 뺀 추가 맵 `Boiling Climb`은 `assets/levels/round4.json`에 남아 있으며, `Main.ROUND_COUNT`를 4로 바꾸면 다시 나옵니다. 원래의 한 파일 버전은 `backup_original/`에 보관되어 있습니다.
